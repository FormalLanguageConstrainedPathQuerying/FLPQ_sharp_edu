> **Abstract:** Context-Free Path Querying library with two algorithms: Azimov's matrix-based algorithm as a generic semiring-parametrized core (one Boolean-adjacency-matrix-driven fixed point per nonterminal, specialized to three semirings — Boolean reachability, singlePath, allPaths) and a straightforward Kronecker-product-based algorithm over RSMs (Boolean reachability only). Inputs are labeled graphs in the flpq-data MatrixMarket format plus either a plain `.cnf` grammar (Azimov) or an RSM (Kronecker).

## Role

Implements Context-Free Path Querying — deciding which pairs of vertices are connected by a path whose label sequence is generated by a context-free grammar. The Azimov algorithm maintains one matrix per nonterminal and iterates `T <- T union (T x T)`-style products to a fixed point (book listing `alg:graphParse`). The Kronecker algorithm takes an RSM instead of a grammar and iterates the tensor product of the RSM transition matrix with the current edge-label matrix, using MS-BFS in place of the book's transitive closure.
