> **Abstract:** Context-Free Path Querying library implementing Azimov's matrix-based algorithm as a generic semiring-parametrized core: one Boolean-adjacency-matrix-driven fixed point per nonterminal, specialized to three semirings (Boolean reachability, singlePath, allPaths). Inputs are labeled graphs in the flpq-data MatrixMarket format and plain `.cnf` grammars.

## Role

Implements Context-Free Path Querying — deciding which pairs of vertices are connected by a path whose label sequence is generated by a context-free grammar. The Azimov algorithm maintains one matrix per nonterminal and iterates `T <- T union (T x T)`-style products to a fixed point (book listing `alg:graphParse`).
