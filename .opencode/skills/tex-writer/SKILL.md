# TeX and LaTeX Writing

Before generating TeX/Tikz output or compiling LaTeX documents, read
[`docs/developer/guides/tex-conventions.md`](/docs/developer/guides/tex-conventions.md) —
it is the single source of truth for nicematrix v6+ `\Block` syntax, the
lualatex triple-check, `array` environment math-mode rules, the template
catalog in `data/`, golden-test template fragility, and Tikz `\graph` with the
`graphdrawing` library.
